# Academic Pages publication files

Upload the eight `.md` files in this folder to the `_publications` folder of `yujin-song-ling/yujin-song-ling.github.io`.

On GitHub:

1. Open `_publications`.
2. Delete the template's example publication files.
3. Select **Add file → Upload files**.
4. Upload all eight `.md` files.
5. Commit directly to the `master` branch.
6. Wait for the Pages deployment to finish.

Dates written as January 1 are sorting dates because the CV provides only publication years. Replace them with exact publication dates if desired. PDF, DOI, slides, and BibTeX links were omitted because they were not listed in the CV; add them only when the correct URLs are available.
