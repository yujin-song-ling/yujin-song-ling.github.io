# Academic Pages conference presentation files

Upload the eleven `.md` content files in this folder to the `_talks` folder of `yujin-song-ling/yujin-song-ling.github.io`.

On GitHub:

1. Open `_talks` at the repository root.
2. Select **Add file -> Upload files**.
3. Upload the eleven presentation `.md` files, not this README.
4. Commit directly to the `master` branch.
5. Wait for the Pages deployment to finish.

The files use the Academic Pages `talks` collection. The visible navigation and page title can still be renamed to **Conference Presentations** while the internal folder remains `_talks`.

Dates written as January 1 are sorting dates because the CV provides only a publication year for those presentations. Replace them with exact presentation dates if desired.
