# Academic Pages teaching files

Upload the two course `.md` files in this folder to the `_teaching` folder of `yujin-song-ling/yujin-song-ling.github.io`.

On GitHub:

1. Open `_teaching`.
2. Delete the template example files.
3. If the empty folder disappears, create `_teaching/README.md` first.
4. Select **Add file → Upload files** inside `_teaching`.
5. Upload the two course `.md` files, not this README.
6. Commit directly to the `master` branch.
7. Wait for the Pages deployment to finish.

The dates in the front matter represent the most recent semester listed for each course and control display order. The complete teaching history appears in each page body.
